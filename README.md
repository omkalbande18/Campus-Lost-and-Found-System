# Campus Lost & Found System (C++)

The **Campus Lost & Found System** is a menu-driven C++ application designed to help students and staff report, search for, and recover lost items within a campus. It provides a simple way to register lost and found items and match them based on their names.

## Features
- **Report Lost Items:** Register lost items with the owner's name, contact details, location, and date.
- **Report Found Items:** Record found items along with the finder's details and the location and date where the item was found.
- **Find Lost Items:** Search for a lost item and check whether a matching found item is available.
- **Item Matching:** Match lost and found records using the item name and display a 100% match score when the names are identical.
- **Claim or Return Items:** Update the status of a found item to "Returned" when it has been collected.
- **Display Records:** View all registered lost items and found items.

## Technologies Used
- **Programming Language:** C++
- **Concepts:** Object-Oriented Programming (OOP), Inheritance, Polymorphism, Function Overriding, Constructors, Virtual Functions, Dynamic Memory Allocation, and Runtime Type Casting.

## Objective
The main objective of this project is to simplify the process of managing lost and found items on campus and help students and staff identify and recover their belongings efficiently.

## How to Run
1. Compile the source file using a C++ compiler.
2. Run the generated executable.
3. Select an option from the main menu to report, search, or manage items.

This project is developed as an academic implementation of a Campus Lost & Found System using C++ and Object-Oriented Programming concepts.
